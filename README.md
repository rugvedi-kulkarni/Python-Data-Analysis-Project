# Student Data Analysis Using Core Python

## 📌 Project Overview

This project focuses on analyzing a student dataset containing approximately 185,667 records using Core Python.

The project consists of 15 data analysis questions designed to practice Python programming, structured data processing, conditional logic, loops, and basic statistical calculations.

The dataset is processed using Python's built-in file handling and data manipulation capabilities, without relying on data analysis libraries such as Pandas or NumPy.

## 🎯 Project Objectives

- Analyze a large student dataset using Core Python.
- Practice reading and processing structured text files.
- Apply loops, conditional statements, lists, and variables to solve analytical problems.
- Calculate counts, averages, and other relevant statistics.
- Compare student data across different regions and categories.
- Develop problem-solving and data interpretation skills.

## 📂 Dataset Information

- **Dataset:** `student_record.txt`
- **Number of records:** Approximately 185,667
- **File format:** Text file (`.txt`)
- **Field delimiter:** Semicolon (`;`)
- **Data processing:** Python file handling and string operations

The dataset is processed record by record to extract the required information for each analytical question.

> Note: The dataset is not included in this repository. Its source, license, and field definitions should be documented when verified.

## 🔍 Analysis Performed

The project contains 15 analytical questions covering student-related data.

The analysis includes tasks such as:

- Counting students from a particular region.
- Calculating average Mathematics marks for a selected region.
- Filtering records based on specified conditions.
- Comparing student groups using dataset fields.
- Performing other data analysis operations based on the 15 questions.

The exact questions, methods, and results are documented in `report.md`.

## ▶️ How to Run the Project

### Prerequisites

- Python 3 installed on your computer.
- The `student_record.txt` dataset available locally.
- The Python script `code.py`.

### Steps

1. Clone or download this repository.
2. Place the permitted dataset in the expected local location.
3. Open a terminal in the project directory.
4. Run the Python script:

```bash
python code.py
```

5. Review the output for each analytical question.

**Important:** Update any machine-specific absolute file paths in the script before running it on another computer. A relative file path is preferable for portability.
